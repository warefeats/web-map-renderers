# The Mapbox candidate is mapbox-gl 1.13.3, not the current release

Mapbox GL JS v2 and later are licensed only to holders of a Mapbox account under the Mapbox Terms of Service, which incorporate the Mapbox Product Terms. Section 1.5(iv) of the Product Terms dated 2026-07-21 forbids using any Mapbox SDK to "benchmark against" a product that is a substitute for or competes with a Mapbox product, and sections 3.40, 3.63 and 3.64 define GL JS itself as such an SDK. Running current mapbox-gl beside maplibre-gl is inside that language whether or not the numbers are published, and every map instantiation would also bill a map load and send telemetry. We therefore measure mapbox-gl 1.13.3, the last BSD-3-Clause release and the code MapLibre forked, and frame the page as the fork measured against its origin rather than as a comparison with the current Mapbox product. The alternative, asking Mapbox for written consent to include the current release, remains open and would add a candidate without changing anything else.
