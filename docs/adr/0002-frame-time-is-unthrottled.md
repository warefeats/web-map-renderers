# Frame time is measured unthrottled, in headless Chromium

Frame time is sampled with vsync and the frame-rate limit disabled, in Playwright's headless shell with the ANGLE Direct3D 11 backend, as a fixed number of camera steps advanced on the map's own render event. A 60 Hz display cap would hide most of the difference between renderers, because any renderer that finishes a frame in under 16 ms scores the same, and the rig is driven over ssh in a session with no interactive desktop, where only the headless shell with ANGLE flags gets the GPU with hardware compositing. The cost is realism: nobody's screen runs unthrottled, so the numbers are relative renderer cost per frame, not what a user sees, and the page says so. The alternative of vsync-on long-frame counting was rejected for the first reason; running a headed browser in the interactive session through the Task Scheduler works but is not something a reader without a monitor can rerun.
